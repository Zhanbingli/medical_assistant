## 🔍 核心实现细节

### **搜索策略决策逻辑**
```python
# SearchStrategy.decide_search_strategy()
# 策略1：知识库为空 → 仅网络搜索
if total_chunks == 0:
    use_local = False
    use_web = True
    reason = "知识库为空，使用网络搜索"

# 策略2：知识库内容过少 → 本地+网络混合
elif total_chunks < 100:
    use_local = True
    use_web = True
    reason = "知识库内容较少，使用本地+网络混合搜索"

# 策略3：知识过时 → 本地+网络（包含PubMed）
elif 超过30%文件>5年:
    use_local = True
    use_web = True
    reason = "部分知识可能过时，建议结合网络搜索"

# 默认：仅本地搜索
else:
    use_local = True
    use_web = False
    reason = "知识库充足，使用本地搜索"
```
